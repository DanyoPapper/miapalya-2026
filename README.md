## Gyors indítás

```bash
git clone https://github.com/FELHASZNALOD/miapálya-2026.git
cd miapálya-2026/backend
npm install
cp ../.env.example ../.env   # szerkeszd a .env fájlt
npm run dev
```

## Deployment

- **Frontend:** Cloudflare Pages (automatikus, minden push-ra)
- **Backend + DB:** Railway (GitHub Education = ingyenes Pro)
